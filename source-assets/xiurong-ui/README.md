# XIURONG UI assets

Generated with the built-in GPT image generation tool for the user-approved XIURONG interface. Provenance and original files are listed in `asset-provenance.json`. The bitmap assets are decorative scenes and instrument imagery; all interface text, buttons, navigation and business data are implemented as native UniApp controls.

Prompt set summary (for reproducing the direction):

- `arch-room.jpg`: high-end blush/ivory beauty treatment room, luminous curved wall, treatment bed, warm light, arched composition, no UI and no text.
- `silk-banner.jpg`: pale blush silk folds, soft daylight, subtle cherry blossoms and gift box at the side, clear central space for live interface copy, no text.
- `skincare-banner.jpg`: premium beauty portrait and pale pink editorial skincare banner, balanced negative space for live headings, no text or embedded controls.
- `devices.png`: transparent horizontal studio atlas of four complete beauty instruments based on supplied equipment references; blue/white 9D standing machine, black/gold AI machine, champagne super-thermage tower and compact gold AI device, isolated with clear gutters, no UI or text.

The generated source PNGs were resized and compressed for packaging. The transparent atlas is clipped with measured CSS viewports so each instrument preserves its proportions. The local `icons/` and `wordmark.svg` are code-authored geometric vectors, not generated raster UI screenshots.
