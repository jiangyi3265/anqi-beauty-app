# 历史发布脚本归档

用于换电脑后查阅发布、备份、验证和回滚实现。以下操作已执行过；不要将这些目录当作下一次发布包直接运行。

| 目录 | 用途和原始基线 |
| --- | --- |
| `deploy-v1.1.35` | 1.1.34 → 1.1.35，含发布后配置脚本 |
| `deploy-v1.1.36` | 1.1.35 → 1.1.36，含收益兑现只读核对 |
| `deploy-v1.1.38` | 1.1.36 → 1.1.38，无发布后配置，Java 不变 |
| `data-fix-20261023` | 已确认的隐私政策/门店修复与停用门店只读检查 |
| `vip-catalogue-20261024` | 六档 VIP 套餐更新脚本及前后配置；保留历史订单快照 |

1.1.37 已作废，不可部署。归档不包含 `release.tgz`、校验和、构建产物、数据库备份、线上快照或运行结果；完整历史发布记录在服务器 `/opt/anqi/releases/`。

归档脚本有固定版本、服务器路径和校验前提，且部分会修改正式配置/数据。只有 `node --check`、`bash -n` 可用于本地语法检查；不要为了验收归档在生产环境重跑脚本。套餐更新中的三个 JSON 仅为当时的目录配置和预期商品字段，不包含会员或订单。

下一次发布以新的版本和服务器实际基线准备独立发布包。新电脑开发说明见 [`docs/换电脑开发与部署交接.md`](../../docs/换电脑开发与部署交接.md)。
