# 换电脑开发与部署交接

交接日期：2026-10-24。三个仓库均使用 `main`；本地 `*-cards` 目录是工作树，不是额外项目，也不需要在新电脑复制。

## 获取完整源码

在同一个父目录下克隆三个仓库：

```sh
git clone https://github.com/jiangyi3265/anqi-beauty-app.git
git clone https://github.com/jiangyi3265/anqi-beauty-admin.git
git clone https://github.com/jiangyi3265/anqi-beauty-backend.git
```

- app：小程序、H5、Node 业务服务、商品目录、图片素材、验收及部署脚本。
- admin：Vue 管理后台；`.env.development`、`.env.production` 是可提交的公开构建参数。
- backend：Java 登录、权限、菜单和 Node 代理，以及新开发库所需的 SQL。

代码版本为 1.1.39。2026-10-24 已按确认方案更新六档 VIP 套餐，每档一套方案、光屿五选一和明星三选一。已有订单保留购买时快照。1.1.37 已撤销、从未上线，不部署该版本。

## 新电脑安装与本地开发

准备 Node.js 24、npm、JDK 8、Maven；需要完整后台联调时再准备本地 MySQL、Redis。Windows 可使用 PowerShell 或 WSL，服务器发布脚本使用 Linux Bash。

app 与 admin 分别执行 `npm ci`，不能复制旧电脑的 `node_modules`。参考各仓库 `.env.example` 配置本地参数。app 的 `.env` 由启动命令读取；Java 需要在 IDE 或进程环境中配置变量，不会自动读取 `.env`。开发环境使用独立随机 `ADMIN_PASSWORD`、`INTERNAL_SECRET`，Node 与 Java 的内部密钥保持一致；保持 `PAYMENT_MODE=off`，不要用线上库做开发测试。

本地启动、Java 新库初始化顺序和初始管理员设置见 [三端协作开发](协作开发.md) 及 backend 的 `sql/README.md`。初始化 SQL 只能用于新开发库，不能重新导入线上库。

## 构建与验证

app 仓库：

```sh
node tools/vip-package-acceptance.cjs
node tools/super-vip-acceptance.cjs
node tools/legacy-members-acceptance.cjs
VITE_API_BASE=https://anqiht.okam.top/api npm run build:h5
VITE_API_BASE=https://anqiht.okam.top/api npm run build:mp-weixin
```

前三个脚本使用临时数据与本地测试服务，不写入正式数据库。上面构建命令使用 Bash 的环境变量语法；PowerShell 请先设置 `$env:VITE_API_BASE='https://anqiht.okam.top/api'`，然后执行 `npm run build:h5` 和 `npm run build:mp-weixin`。

- H5 产物：`dist/build/h5`。
- 微信产物：`dist/build/mp-weixin`；安装微信开发者工具后导入该目录，使用有权限的微信账号登录上传。版本号和备注按下一次发布计划填写。
- admin 执行 `npm run build:prod`，产物是 `dist/`。
- backend 按需执行 `mvn -pl ruoyi-admin -am package -DskipTests`；仅前端/Node 更新时不替换 Java JAR。

## 继续维护现有服务器

公开服务为 H5 `https://anqi.okam.top`、后台 `https://anqiht.okam.top`，业务接口为 `https://anqiht.okam.top/api`。生产配置、密钥和数据继续留在服务器，不依赖旧电脑：

| 内容 | 服务器位置 |
| --- | --- |
| Node 业务源码及依赖 | `/opt/anqi/business/` |
| Node 运行时 | `/opt/anqi/node/bin/node` |
| 业务环境配置 | `/opt/anqi/shared/business.env` |
| 运维凭据 | `/opt/anqi/shared/credentials.json` |
| Java 程序 | `/opt/anqi/ruoyi/ruoyi-admin.jar` |
| H5 站点 | `/www/wwwroot/anqi.okam.top/` |
| 管理后台站点 | `/www/wwwroot/anqiht.okam.top/` |
| 历次发布和备份 | `/opt/anqi/releases/`、`/opt/anqi/backups/` |

服务名称包括 `anqi-business`、`anqi-backend`、`anqi-mysql`、`anqi-redis`。SSH 账号、数据库密码、微信商户证书、AppSecret 需通过私密渠道或有权限的服务器配置获取，不能提交 GitHub。

`static/uploads/` 是运行中上传的图片，不在 Git 中。新电脑使用现有线上图片地址即可；新服务器迁移时，需要通过受控通道迁移上传目录、业务数据库及环境配置，单独克隆源码不会带入线上会员和订单。
