# 安棋美容后台使用说明

后台网址：https://anqiht.okam.top

使用管理员账号登录，输入图片中的验证码即可进入。后台只保留三组店务菜单；工作台可以直接进入订单、预约、商品和会员管理。

## 添加或修改商品

进入“日常业务 → 商品管理”，点击“添加商品”。填写商品名称，上传图片，选择到店服务或实物商品，再填写价格和库存数量，最后点击“保存”。

如果提供疗程套餐，打开“是否提供疗程套餐”并填写整个疗程的价格。首页推荐、贵宾礼品和体验礼品在“更多设置”中选择。

点击列表中的“修改”可调整商品内容。暂时不卖的商品点击“下架”，恢复销售时点击“上架”。图片中如果写有价格，修改售价时也应更换图片。

## 配置不同门店的地址

进入“日常业务 → 门店管理”，每家分店点击一次“添加门店”，分别填写门店名称、门店图片、联系人、联系电话、详细地址和营业时间，再保存。已有门店点击“修改”即可调整本店信息。分店名称建议包含所在区域或路名，方便顾客选择。

用户端的所有门店、下单和体验卡预约会按所选门店显示地址及电话；购买服务的预约使用订单对应的门店。关闭门店的上架开关后，该店不再接受新订单或预约，历史记录仍保留对应门店信息。

## 维护体验卡项目

体验卡默认提供 9D变脸术（单部位，价值999元）、AI大师（单部位，价值6980元）和超玛吉（单部位，价值6980元），使用对应项目海报，领取后免费预约。

在“商品管理”中修改项目，“商品副标题”填写体验范围，“项目展示价值”填写展示金额。项目价值用于说明体验内容，领取和预约无需支付；库存和上下架可按实际情况维护。

## 处理顾客订单

进入“日常业务 → 订单管理”。可以用订单号、顾客姓名或商品名称查找订单。

- 顾客已在线下付款：核实金额后点击“确认已收款”，填写收款说明。
- 实物需要发货：点击“填写发货信息”，填写快递单号或到店领取说明。
- 商品已交付或服务已完成：点击相应的确认按钮。
- 未付款订单不再需要：点击“取消订单”，库存数量会自动恢复。

微信线上付款尚未配置，因此“确认已收款”必须以实际线下收款为依据，不会自动扣款。

## 处理预约

进入“日常业务 → 预约管理”。顾客完成服务后点击“完成服务”，预约和对应订单会一起变为已完成。取消预约时点击“取消预约”。

## 管理会员

在“日常业务 → 会员管理”中搜索会员姓名或联系电话，查看会员资格、停用状态和订单关联记录。

“更多操作”包含领取礼品资格、重置会员密码、停用或恢复会员账号。

## 发放礼品

在“礼品领取”中查看贵宾和体验礼品领取记录。实际交付商品后点击“确认已发放”。

贵宾和体验礼品的领取记录在“礼品领取”中，交付后同样点击“确认已发放”。

## 修改活动、商家与页面内容

“店铺设置”菜单中可以维护活动、合作商家和店铺配置；门店位于“日常业务”菜单。店铺配置页面分为“店铺设置”“首页图片”“其他页面图片”“协议说明”四个标签。图片直接上传，不需要填写地址或路径。

所有修改保存后，顾客重新打开相应页面即可看到更新。日期与完整时间使用北京时间，以“年、月、日、时、分、秒”显示；只有日期的历史记录保留年月日，不补造发生时间。
