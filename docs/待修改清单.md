# 暨美丽发布验收修改清单

## 已确认的优先级

1. 首页布局、栏目顺序、入口位置和底部导航保持原小程序结构；本轮只替换指定图片和文案。
2. 客户端、后台和运行日志中的品牌统一为“暨美丽”，不显示安琪美容、安棋美容或玥色塑美。
3. 线上商品目录保留一个正式展示商品“逆龄肽奢护焕颜套”。页面和后台不显示“测试”“模拟”等字样。
4. 活动专区由后台维护活动名称、说明、时间和关联商品；客户端展示说明并跳转关联商品购买。
5. 后台以中文和简单操作为主，时间格式按年月日时分秒；不向后台用户展示后端源码或开发工具。
6. 微信登录已改为唯一登录方式；服务器当前尚未配置 AppID/AppSecret，因此真实 wx.login 和真机联调待补凭证后执行。微信支付仍为关闭状态，不能把离线收款当作在线支付成功。
